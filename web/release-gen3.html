GEN 3 RELEASE PREVIEW: 1.36.0

All 386 Pokémon from Kanto, Johto and Hoenn for the Waveshare ESP32-S3-Touch-AMOLED-1.75.

⚠️ TWO STEPS ARE REQUIRED.
Flashing the firmware alone is incomplete. After step 1, reconnect the board and complete step 2 to copy all 386 Pokémon sprites to the microSD.

⚠️ Use desktop Chrome or Edge. This browser does not support Web Serial.

1Flash firmware 1.36.0

Connect the board by USB, press install and select its serial port.

Browser not supported (use Chrome/Edge). Needs HTTPS or localhost.

Updating? Leave Erase device unchecked to keep your Pokémon and progress. Erase only a completely new board or a save you intentionally want to delete.

2Install all 386 sprites — required

Insert a microSD card. Close the flashing dialog, connect the board again, then press the single install button. It safely sends the complete Kanto/ Johto package first and the Hoenn package second.

Do not unplug the board or remove the microSD during transfer. Existing Gen‑2 cards may use the same full process safely.
